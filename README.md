# Apache 开源协议
**Apache License** 是由 Apache 软件基金会（ASF）发布的开源许可证，最常用的是 **Apache License 2.0**。它是一种宽松式许可，给予使用者极大的自由度，并且包含明确的专利授权，非常适合企业级商业化应用。

---

## 核心权利
使用 Apache License 2.0 发布的代码，您享有以下权利：
- **永久、全球性、免费** 的版权许可：可复制、修改、衍生、发布、公开运行和传播代码。
- **明确的专利授权**：每个贡献者都将自己贡献部分的专利权授予使用者，防止后期专利索赔（含专利报复条款）。
- **自由商业化**：允许将代码用于闭源商业产品，无需公开衍生代码（与 GPL 不同）。
- **分发限制少**：可以仅以二进制形式分发，需保留必要声明。
---
## 必须遵守的条件
在享受上述权利的同时，您必须满足以下 **三个核心义务**：
1. **保留版权和许可声明**  
   在源码、衍生物或二进制发布中，必须附带原作者的版权声明、Apache License 2.0 全文以及免责声明。
2. **明确标注修改**  
   如果修改了源文件，必须在修改过的文件中添加显式声明（如“该文件已被修改”），并注明修改者和修改日期。
3. **保留 NOTICE 文件**  
   如果原项目包含 `NOTICE` 文件，您必须将其保留在衍生作品中，不能修改或删除其中的归属信息（但不能以此暗示原作者认可您的产品）。
---
## 主要特点
- **专利信守条款**：一旦被许可方对代码的任何贡献者提起专利侵权诉讼，其所获得的专利许可将自动终止。有效防止专利流氓攻击开源项目。
- **无担保**：软件按“现状”提供，不做任何明示或暗示的担保，因使用造成的风险由使用者自行承担。
- **与 GPL 的兼容性**：Apache 2.0 与 GPLv3 兼容，但不兼容 GPLv2（因专利条款缺失）。
- **商誉保护**：不允许使用贡献者的名义进行推广，除非获得专门授权。
---
## 适用场景
Apache License 2.0 在业界广泛被采用，典型项目包括：
- Kubernetes
- Android 开源项目（AOSP）
- Apache Hadoop、Spark
- TensorFlow
- Rust 语言及标准库
它适合那些希望代码被广泛使用、同时保护自身专利和声誉的个人、团队或公司。
